# Support

## Usage Questions

For usage questions, please use the GitHub Discussions feature in the Arcon
repository. This is the best place to ask how to use Arcon, configure the
inference runtime, or understand the architecture.

## Bugs

Please report bugs using the GitHub issue tracker. Use the bug report template
and include all requested information.

## Feature Discussions

For feature requests and architectural discussions, use the GitHub issue tracker
with the appropriate template. Architecture discussions are particularly welcome
for changes that affect memory, retrieval, cognition, or reflection.

## Security Issues

If you discover a security vulnerability, please follow the policy in
SECURITY.md. Do not disclose security issues publicly in GitHub issues.

## Contributing

See CONTRIBUTING.md for how to contribute code, tests, or documentation.
