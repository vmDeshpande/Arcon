# Roadmap

## Phase 1: Foundation

- Text message input
- Ollama response generation
- Short-term conversation storage
- Recent context retrieval
- Event bus
- Timestamped logs

## Later Phases

The following are not part of Phase 1:

- Long-term memory
- Personality engine
- Screen awareness
- Browser or desktop automation
- Web learning
- Reflection systems
- Proactive behavior
- Electron frontend
